SOLAR SYSTEM PROJECT:
> Interactive, cinematic 3D web-site

** 🌐 Live Website:**
https://shuhratkhon.github.io/solar_system_project/

## 🛠️ Technologies:

- HTML5 (Website structure)
- CSS3 (Interface and visual design)
- JavaScript (Application logic)
- Three.js (3D, Camera interaction, Post-processing)
- Supabase (live like system)
- GitHub Pages (Website hosting)

## ✨ Innovative Features :

- Interactive 3D environment
- Free Camera Exploration (but Sun is locked at the center)
- Animated Planetary System (planets rotate and orbit Sun,
while other space objects also move subtly to make it feel alive)
- Cinematic Sun (it has dynamic glowing/pulsing effect)
- Interactive Planet Detection (hovering over them identifies them,
clicking opens different information window)
- Separate 3D Planet Showcase (while on Planet Information Window,
we have clone of selected planet with Solar System continue running in the background)
- Global Like System (persistent, anonymous one-like-per-user system with
real-time update using Supabase)
